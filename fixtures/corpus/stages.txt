# Phoneme strings for the *front half* of the pipeline — parse through frame
# generation — captured by `tools/capture-stages.py` alongside
# fixtures/corpus/frames.txt, which is chosen for the renderer instead.
#
# These earn their place by driving a decision the rest of the corpus reaches
# once or not at all. `tools/branch-coverage.py` is how that is measured: it
# counts the device's own visits to each branch, so a thin count here is a
# fact about the fixtures rather than a guess.
#
# Everything is written as real English words, because a phonotactically
# impossible string can exercise a branch and still tell you nothing about
# whether the port is right for speech.

# hunk+0x220c shares that fall out over the phrase's primary stresses. Four or
# more of them splits the step two ways — a bigger one at each end, taken back
# evenly from the middle — so both schemes need driving. A question falls to
# 115 rather than 110, which is the only mark a `?` still leaves on this
# build's contour. And hunk+0x2160 skips its whole body when the phrase has no
# primary stress in it, which needs a phrase with no stress digit at all.
DHAH KAET SAET
IHZ DHIH4S AH KWEH4SCHAHN?
WEH4R AA4R DHAH SEH4VEHN LAO4NX WER4DZ?
WAH4N TUW4 THRIY4 FOH4R FAY4V?

# hunk+0x1fd8 reads `arr3` through the cursor at A5+0x68 like everything else
# in this stage, so a dash anywhere but the first phrase of an utterance lands
# at a different index. Nothing else in the corpus puts one there.
GUH4D BAY4, SOW4 LAO4NX - MAY4 FREH4ND.

# hunk+0x23ce reconciles each stressed syllable with the next, and what it
# does depends on how far apart they are: back to back it flattens both, and
# with room between them it widens both, on a three-band ladder of one, two or
# more syllables in the gap. Nothing else in the corpus puts two unstressed
# syllables in a row between two stressed ones.
SIY4 DHAH KAET RAH4N
SIY4 DHAH KAET AHN RAH4N
SIY4 DHAH KAET AHN DHAH RAH4N
SIY4 DHAH KAET AHN DHAH GRAAS RAH4N.

# hunk+0x2642 moves two stressed syllables half way towards each other when
# the earlier one ends *below* where the later one starts. Declination alone
# never does that -- the pitch only falls -- so it takes the stress-level
# scaling at hunk+0x22d6 lifting a later syllable back above an earlier one,
# which needs a low stress digit followed a few syllables later by a high one.
AH4 DHAH BIY9 DHAH SIY4 DHAH DIY9 DHAH IY9.
EY4 DHAH BIY9 DHAH SIY9 DHAH DIY9 DHAH IY9 DHAH EH9F.
